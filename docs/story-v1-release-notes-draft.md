# Thoughtcraft Story V1 — RC1 release-note draft

**Local candidate only. Public version, licensing and publication are pending owner approval.** The manifest remains `0.1.0`; RC1 is an artifact label, not an Obsidian prerelease version.

Thoughtcraft helps give shape to ideas: capture freely, connect thoughts and add structure when it helps. Story is the first specialization of a broader creative-environment vision.

The candidate includes:

- Markdown-backed entities, custom types, five property kinds, reusable schemas and generic/custom UUID relations.
- Workspaces and a free spatial Brainstorm view, independent of narrative order.
- Story collections, native Markdown writing and generic Focus.
- Ordered Story Sections and Scenes, plus an Unplaced area for fragments.
- Optional Plot Threads, multiple memberships per Scene, highlighting/filtering and progression through the canonical Plot sequence.
- An integrated Guide explaining both the controls and narrative concepts.
- Guarded metadata writes, explicit partial-write recovery and checks against stale relations; narrow layouts also handle long titles.

RC1 packaging includes the three install assets and embedded third-party attribution. Desktop Obsidian **1.14.5 or later** is required. Linux on 1.14.5 is verified; later versions, Windows and macOS are unverified. Mobile is disabled for this candidate.

Configuration stays v8. Native checks cover a fresh packaged install, a rebuilt M7 source revision upgrade, a retained M10 v8 snapshot, restarts and a 500-Scene/100-Thread case. They are automated engineering evidence, not human beginner acceptance or proof of arbitrary-vault scalability.

Before updating, [back up notes and configuration together](backup-and-recovery.md). Two-note edits are not atomic; failures are actionable, without guaranteed rollback or global undo.

Creative Environment Templates, independent desktop hosting, formulas/evaluation profiles, nested chapters, advanced timelines, AI and dedicated Character Arcs remain future concepts. They are not part of this candidate.
